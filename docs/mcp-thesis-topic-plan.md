# 本科毕业论文选题方案（应用统计学）

## 1. 选题结论

- 题目：《基于LoRA微调的大语言模型中文金融情感分类研究》
- 方向：大模型（LLM）+ 文本情感分析 + 统计评估
- 范围：只做“情感分类”部分，不做“情绪指数预测股价”部分（不写爬虫、几乎不做数据清洗），把统计分析做深
- 硬件：单卡 RTX 3090（24GB），可完成 8B 以下模型的 QLoRA 微调与推理

## 2. 数据

- 唯一数据集：FinFE（BBT-CFLEB 基准，中文金融社交媒体文本情感三分类：消极/中性/积极）
- 规模：训练 8000 / 验证 1000 / 测试 1000，已标注、已划分
- 来源：GitHub `supersymmetry-technologies/BBT-FinCUGE-Applications`
- 参照基线：原论文中 GPT2、T5、FinBERT 等模型准确率约 79%-80%
- 预处理：仅做去重、冲突标签检查、划分交集检查（约半天）

## 3. 研究问题

| 编号 | 研究问题 | 对应实验 |
| --- | --- | --- |
| RQ1 | 大模型比传统方法强吗？差异是否显著？ | 实验一：多模型对比 |
| RQ2 | 标注数据量多少时大模型才值得用？（核心） | 实验二：样本量实验 |
| RQ3 | 模型越大越好吗？性价比如何？ | 实验三：模型规模实验 |
| RQ4 | 大模型的置信度可靠吗？拒绝低置信度样本能否提高准确率？错在哪里？ | 实验四：校准、选择性预测与误差分析 |

## 4. 对比模型

| 类型 | 模型 | 作用 |
| --- | --- | --- |
| 传统机器学习 | TF-IDF + 逻辑回归、TF-IDF + SVM | 基准线 |
| 预训练小模型 | 中文 BERT（如 RoBERTa-wwm-ext） | 经典深度学习方法 |
| 大模型（不训练） | Qwen3-8B 零样本、少样本提示 | 原生能力 |
| 大模型（微调） | Qwen3-8B + QLoRA | 本文重点 |

工具：LLaMA-Factory（微调）、transformers、scikit-learn、statsmodels。

## 5. 实验设计

### 5.1 实验一：多模型对比（RQ1）

- 指标：Accuracy、Macro-F1、各类别 Precision/Recall、混淆矩阵
- 每个模型 3-5 个随机种子，报告均值 ± 标准差
- McNemar 检验：同一测试集上两模型对错差异是否显著
- Bootstrap 95% 置信区间（F1）
- 多重比较使用 Holm 校正

### 5.2 实验二：样本量实验（RQ2，核心创新）

- 训练样本量：100、250、500、1000、2000、4000、8000
- 每个样本量重复抽样 3 次
- 学习曲线（带置信带）
- 双因素方差分析：检验“模型 × 样本量”交互效应
- 幂律函数拟合学习曲线；Bootstrap 估计大模型与 BERT 差距不再显著的临界样本量及其置信区间

### 5.3 实验三：模型规模实验（RQ3）

- QLoRA 微调 Qwen3-1.7B / 4B / 8B
- 比较性能、显存占用、训练时间
- 与实验二结合：小模型 + 多数据 vs 大模型 + 少数据

### 5.4 实验四：可靠性与误差分析（RQ4）

- 置信度校准：ECE、Brier 分数、可靠性图；尝试温度缩放
- 选择性预测：按置信度拒绝低把握样本，绘制覆盖率-准确率曲线，比较 AURC
- 误差分析：易错类别（通常为中性类）、反讽、否定句、股市黑话
- 卡方检验：错误是否集中于特定文本特征（长度、否定词等）

## 6. 创新点

1. 研究场景：中文金融社交媒体三分类（含中性类、口语化文本），补充已有研究多为英文或中文二分类的不足
2. 统计推断：重复实验、McNemar 检验、Holm 校正、交互效应方差分析，给出临界样本量的区间估计（已有研究只做单次描述性比较）
3. 可靠性评价：置信度校准 + 选择性预测（低置信度样本交由人工），在金融情感分析中研究较少

### 6.1 与最相关研究的区别

| 研究 | 已做工作 | 不足（本文改进点） |
| --- | --- | --- |
| Paredes Amorin 等（2025，arXiv:2512.00946） | FinBERT vs Qwen3-8B 等，5%-100% 训练数据比例实验 | 中文数据仅二分类；无显著性检验；无置信度分析 |
| Cheng（2025，Finance & Economics） | LoRA/QLoRA 微调 Qwen3-8B、Llama-3.1-8B vs FinBERT | 仅英文数据；无样本量与可靠性分析 |
| DISC-FinLLM | 在 FinFE 上评测 LoRA 微调大模型 | 仅报告准确率 |

## 8. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 大模型优势不显著 | 如实报告，结论同样有意义（小数据/大数据下的选择建议） |
| 实验组合多、耗时长 | 样本量实验优先用 BERT 与 Qwen3-1.7B/4B，8B 仅跑关键点 |
| 编程基础不足 | 使用 LLaMA-Factory 等现成框架，减少手写训练代码 |
