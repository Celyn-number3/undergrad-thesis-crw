# 第5章 结论与展望

## 5.1 主要结论

本文以中文金融社交媒体情感分类数据集 FinFE 为对象，在单张 RTX 3090 显卡上系统比较了传统机器学习、预训练语言模型和开源大语言模型三类方法，并从统计推断、置信度可靠性和数据质量三个角度对结果进行了分析。主要结论如下。

**（1）公开基准存在明显的数据质量问题，必须先清洗再评估。** FinFE 公开评估集中有 1092 条文本原样出现在训练文件中，其中 228 条标签不一致。如果直接使用公开文件，模型对见过的原句准确率可达 93%～97%，TF-IDF 基线的宏平均 F1 虚高 8.1 个百分点，TF-IDF 与 RoBERTa 的真实差距被缩小约三分之二。经去重和重新划分后，本文得到无泄漏的训练集、验证集和测试集（8802 / 979 / 1713 条）。

**（2）LoRA 微调的大模型取得了最好的分类效果，但领先幅度较小。** 在清洗后的测试集上，TF-IDF 基线的宏平均 F1 约为 0.70，RoBERTa-wwm-ext 约为 0.778，三个 LoRA 微调大模型为 0.798～0.807。零样本和少样本提示的大模型 F1 只有 0.63～0.70，不如微调后的 RoBERTa，说明在该任务上有监督微调仍然必要。三个大模型之间的差异不显著（方差分析 p = 0.14）。

**（3）统计显著性的结论取决于所考虑的不确定性来源。** 以 3 个随机种子反映训练随机性时，三个 LoRA 大模型都显著优于 RoBERTa（Tukey 检验 p = 0.0014～0.021）；以测试样本抽样误差为依据时，McNemar 检验经 Holm 校正后不显著（p = 0.55～0.69），配对 Bootstrap 的 F1 差值约为 0.018～0.019，95% 置信区间下限接近或略低于 0。因此，LoRA 大模型的优势是稳定的，但幅度只有约 2 个百分点，在 1713 条的测试集上难以被严格证实。

**（4）零样本大模型严重过度自信，微调和温度缩放可以有效改善。** 零样本 Qwen3-8B 的平均置信度为 96.4%，而准确率只有 67.1%，ECE 为 0.294；LoRA 微调后 ECE 降至 0.035～0.085，再经温度缩放可降至 0.013～0.030。选择性预测结果表明，LoRA 大模型只处理置信度最高的 50% 样本时准确率约为 96%，处理 80% 样本时约为 89%，AURC 优于 RoBERTa，适合“模型处理高置信度样本、人工复核低置信度样本”的应用方式。保形预测在所有模型上都达到了 90% 的目标覆盖率，LoRA 大模型约 78% 的评论只需给出一个类别；按类别校准可将中性类覆盖率从 0.76～0.81 提高到 0.90。此外，宣称校准良好的开源决策模型 Laya 在零样本下 Macro-F1 仅为 0.47～0.50，说明通用模型迁移到中文金融领域时仍需在目标数据上重新检验。

**（5）LoRA 微调对超参数不敏感，资源需求较低。** 训练样本量从 500 条增加到全量，F1 从 0.766 提升到 0.800，边际收益逐渐递减；LoRA 秩在 4～32 之间变化时 F1 稳定在 0.798～0.809；4 比特 QLoRA 的 F1 为 0.807，与 16 位精度相当，峰值显存仅 11.2 GB。

**（6）标注噪声限制了可达到的准确率，中性类是主要难点。** 利用重复标注样本估计，标注一致率为 82.9%（κ = 0.735），标注准确率约为 91%，可视为模型准确率的近似上限。所有模型的中性类 F1 都只有 0.69 左右，而 82% 的标注冲突涉及中性类，说明中性类识别困难在很大程度上来自标注本身的模糊性，而不仅是模型能力不足。

## 5.2 研究不足

本文仍存在以下不足：

（1）**只使用了一个数据集。** 本文的结论基于 FinFE 这一中文金融社交媒体数据集，是否适用于金融新闻、研究报告、上市公司公告等其他类型的文本，还需要进一步验证。

（2）**随机种子数量较少。** 受计算资源限制，每个模型只进行了 3 次独立训练，方差分析的自由度较小，对训练随机性的估计不够精确。

（3）**研究计划有所调整。** 开题时计划比较同一系列不同规模的模型（Qwen3-1.7B、4B、8B），并在 7 个样本量上各重复 3 次绘制学习曲线。实际实验中，模型比较改为三个不同系列、规模相近（7B～9B）的模型，样本量实验也只在少数几个规模上各进行了一次，因此未能系统分析模型规模的影响，学习曲线也较为粗略。

（4）**标注噪声的估计较为粗略。** 91% 的上限基于“各类别错误概率相同”的简化噪声模型，且被重复标注的文本平均更短，并非随机样本，因此只能作为近似参考。

（5）**测试集中存在近似重复。** 本文只去除了完全相同的文本，未处理只相差个别字符的近似重复文本，可能仍有少量泄漏。

（6）**未进行系统的错误类型分析。** 本文未对错误样本按反讽、否定、专业术语等类型进行人工标注和统计检验，对模型错误原因的分析还不够深入。

## 5.3 研究展望

针对上述不足，未来可以从以下几个方面继续研究：

（1）**将情感分类结果用于股价预测。** 本文得到的情感分类模型可以用于对股吧等平台的帖子进行大规模自动标注，再按个股和交易日汇总为投资者情绪指数，检验其对股票收益率、成交量和波动率的预测能力。这需要爬取帖子数据并与行情数据对齐，是本文最直接的后续工作。

（2）**扩展到更多数据和任务。** 在金融新闻、研究报告等多种文本上检验结论的普适性，并尝试细粒度的情感强度分析或面向实体的情感分析。

（3）**改进中性类的识别和标注。** 可以对中性类样本进行多人重新标注，或采用软标签、标签平滑等对噪声更稳健的训练方法，以缓解标注模糊带来的影响。

（4）**更完善的不确定性评估。** 增加随机种子数量，或采用 LoRA 集成等方法，更精确地估计训练随机性，并进一步改进大模型的校准效果。

（5）**比较不同规模的模型。** 在同一模型系列中比较不同参数规模的效果与成本，为资源受限情况下的模型选型提供更全面的参考。
