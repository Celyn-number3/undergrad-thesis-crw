# 第1章 绪论

## 1.1 研究背景

随着互联网和移动终端的普及，股吧、雪球、微博等金融社交媒体已成为中国个人投资者获取信息、交流观点的重要渠道。投资者在这些平台上发布的大量短文本中蕴含着对个股、行业乃至整体市场的情绪倾向。已有研究表明，媒体和网络论坛中的投资者情绪与资产价格、交易量和市场波动存在显著关联 [Tetlock, 2007; 游家兴和吴静, 2012; 段江娇等, 2017; 部慧等, 2018]。因此，如何从海量金融文本中准确、自动地识别情感倾向，是金融科技和计量金融研究中的一个基础问题 [沈艳等, 2019]。

金融情感分析的方法经历了从情感词典、传统机器学习到预训练语言模型的演进。情感词典方法依赖人工构建的领域词表 [Loughran 和 McDonald, 2011]，可解释性强，但难以处理否定、反讽和上下文相关的表达。以 TF-IDF 特征配合逻辑回归、支持向量机为代表的传统机器学习方法，在有标注数据时效果明显提升，但仍停留在词袋层面。以 BERT [Devlin 等, 2019] 为代表的预训练语言模型通过“预训练 + 微调”范式大幅提升了文本分类效果，在金融领域也出现了 FinBERT [Araci, 2019] 以及面向中文的 RoBERTa-wwm-ext [Cui 等, 2021] 等模型。

近年来，以 GPT 系列 [Brown 等, 2020] 和 Qwen3 [Yang 等, 2025] 为代表的大语言模型展现出强大的语言理解与生成能力，金融领域也出现了 BloombergGPT [Wu 等, 2023]、FinGPT [Yang 等, 2023] 等专门模型。但大模型参数量达数十亿，全参数微调的计算成本很高。LoRA [Hu 等, 2022] 和 QLoRA [Dettmers 等, 2023] 等参数高效微调方法只训练少量低秩参数，使 7B～9B 规模的模型可以在单张消费级显卡上完成微调，为普通研究者在特定任务上使用大模型提供了可能。

在这一背景下，一个自然的问题是：经过 LoRA 微调的开源大模型，在中文金融情感分类上究竟比传统方法和 BERT 类模型好多少？这种优势是否在统计意义上可靠？模型给出的置信度能否被信任？现有研究对这些问题的回答还不充分。

## 1.2 研究问题与研究意义

### 1.2.1 现有研究的不足

梳理相关文献（详见第 2 章）可以发现，现有研究在以下几个方面仍有不足：

（1）**以英文数据为主。** 大模型金融情感分析的研究多基于 Financial PhraseBank [Malo 等, 2014]、FiQA 等英文数据集 [Zhang 等, 2023; Fatemi 和 Hu, 2023; Paredes Amorin 等, 2025]，针对中文金融社交媒体短文本的系统比较较少。

（2）**缺少统计检验。** 多数研究只报告单次运行的准确率或 F1 值，在模型差距只有一两个百分点时，很难判断差异来自方法本身还是来自随机性。

（3）**忽视置信度的可靠性。** 实际应用中，模型不仅要给出类别，还要给出可信的置信度，以便把没把握的样本交给人工处理。已有研究指出神经网络和 LoRA 微调的大模型存在过度自信问题 [Guo 等, 2017; Balabanov 和 Linander, 2024]，但在中文金融情感任务上尚缺少系统评估。

（4）**较少检查基准数据本身的质量。** 公开基准通常被直接使用，其中可能存在的重复样本、训练集与测试集重叠以及标注不一致等问题，会影响评估结论，但很少被专门分析。

### 1.2.2 研究意义

**理论意义。** 本文从应用统计学的角度出发，把多种子方差分析、McNemar 检验、Bootstrap 置信区间、多重比较校正、校准分析等方法系统地用于大模型评估，并区分“训练随机性”和“测试样本抽样误差”两种不确定性来源，为模型比较提供了更严谨的统计框架。同时，通过量化数据泄漏和标注噪声的影响，说明了数据质量对评估结论的重要性。

**实际意义。** 本文在单张 RTX 3090（24GB）显卡上完成了全部实验，给出了开源大模型在中文金融情感分类上的性能、成本和可靠性参考，可为券商、基金、财经媒体等机构开展舆情监测时的模型选型提供依据。选择性预测的结果还表明，可以让模型自动处理高置信度样本、把低置信度样本交给人工，从而在准确率和人工成本之间取得平衡。

## 1.3 研究内容

本文以 BBT-CFLEB 基准中的 FinFE 数据集 [Lu 等, 2023] 为研究对象，围绕以下几个问题展开：

（1）**数据质量检查与重新划分。** 对公开数据进行探索性分析，识别重复文本、标签冲突以及训练集与评估集之间的重叠，制定清洗规则，构建无泄漏的训练集、验证集和测试集（8802 / 979 / 1713 条）。

（2）**多类模型的性能比较。** 在同一数据划分下比较三类方法：TF-IDF 配合逻辑回归和支持向量机的传统机器学习基线；BERT 与 RoBERTa-wwm-ext 预训练模型微调；Qwen3-8B、Qwen2.5-7B-Instruct、GLM-4-9B 三个开源大模型的零样本、少样本提示与 LoRA 微调。

（3）**差异的统计推断。** 对需要训练的模型各进行 3 次不同随机种子的独立训练，使用方差分析与 Tukey 事后检验、经 Holm 校正的 McNemar 检验、配对 Bootstrap 置信区间，从不同角度判断模型差异是否显著。

（4）**置信度校准与选择性预测。** 基于标签词的 logit 提取大模型的类别概率，计算期望校准误差（ECE）并绘制可靠性图，检验温度缩放的效果；绘制覆盖率—准确率曲线，比较各模型的 AURC；并用保形预测给出有覆盖率保证的预测集合。此外，评估了开源决策模型 Laya 的零样本表现。

（5）**消融实验。** 考察训练样本量、LoRA 秩和 4 比特量化对微调效果与显存占用的影响。

（6）**数据泄漏与标注噪声分析。** 通过对照实验量化训练集与评估集重叠对评估分数的影响；利用重复标注的样本估计标注一致率和可达到的准确率上限，从数据层面解释中性类识别困难的原因。

## 1.4 研究创新

与已有研究相比，本文的创新主要体现在以下四个方面。需要说明的是，LoRA、QLoRA、标签词概率提取等均为已有方法，本文的贡献在于数据质量分析、评估方法和统计分析层面。

第一，**发现并修正了公开基准数据的质量问题，并量化了其对评估的影响。** 本文发现 FinFE 公开评估集中有 1092 条文本（占 54%）原样出现在训练集中，其中 228 条标签与训练集不一致。对照实验表明，数据泄漏使模型对见过的原句准确率高达 93%～97%，使 TF-IDF 基线的 F1 虚高 8.1 个百分点，并把 TF-IDF 与 RoBERTa 之间的真实差距缩小约三分之二。本文给出了可复现的清洗规则和无泄漏的数据划分。

第二，**区分了两种不确定性来源，对模型差异做出更稳健的判断。** 本文同时使用多种子方差分析（反映训练随机性）以及配对 Bootstrap 和 McNemar 检验（反映测试样本抽样误差）。结果显示，LoRA 大模型相对 RoBERTa 约 2 个百分点的优势，在前一种检验下显著，在后一种检验下仅边缘显著或不显著，由此得出“优势稳定但幅度较小”的审慎结论。

第三，**将校准分析与选择性预测引入中文金融情感分类的大模型评估。** 零样本大模型的平均置信度为 96.4%，实际准确率仅为 67.1%；LoRA 微调后过度自信明显缓解，温度缩放可进一步将 ECE 降至 0.013～0.030。在选择性预测中，LoRA 大模型只处理置信度最高的 50% 样本时准确率约为 96%。进一步引入保形预测后，LoRA 大模型约 78% 的评论可给出有 90% 覆盖率保证的唯一类别；按类别校准还解决了标准做法下中性类覆盖率偏低（0.76～0.81）的问题。

第四，**利用重复标注估计了数据集的标注噪声和准确率上限。** 同一文本两次标注的一致率为 82.9%（κ = 0.735），据此估计标注准确率约为 91%，可视为模型准确率的近似上限；82% 的标注冲突涉及中性类，说明中性类识别困难在很大程度上源于标注本身的模糊性。

## 1.5 论文结构

本文共分为五章，各章内容安排如下：

第 1 章为绪论，介绍研究背景、研究问题与意义、研究内容、创新点和论文结构。

第 2 章为相关理论与方法，介绍文本表示与传统分类方法、Transformer 与预训练语言模型、大语言模型及 LoRA 微调原理，以及模型比较的统计检验、置信度校准、选择性预测与保形预测等方法。

第 3 章为数据与研究方法，介绍 FinFE 数据集的来源、质量检查与清洗过程、探索性分析，以及各模型的实验设置与评价指标。

第 4 章为实验结果与分析，报告各模型的性能比较、统计检验、校准与选择性预测、消融实验、数据泄漏与标注噪声分析、保形预测以及开源决策模型的结果。

第 5 章为结论与展望，总结主要结论，讨论研究的不足，并展望将情感分类结果用于股价预测等后续研究方向。
