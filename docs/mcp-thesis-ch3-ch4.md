# 第3章 数据与研究方法

## 3.1 数据来源

本文使用的数据集为 FinFE（Financial Forum Emotion），它是中文金融评测基准 BBT-CFLEB 中的情感分类子任务 [Lu 等, 2023]。FinFE 的文本来自金融社交媒体上的股民评论，每条评论被标注为消极、中性、积极三类情感之一。与新闻标题、研报等规范文本相比，股民评论篇幅短、口语化程度高，常夹杂股票代码、网络用语和反讽表达，对模型的语义理解能力要求较高。

原论文描述的数据划分为训练集 8000 条、验证集 1000 条、测试集 1000 条，但项目公开仓库中实际提供的文件与之不同：train_list.json 含 16157 条带标签样本，eval_list.json 含 2020 条带标签样本，problem_list.json 含 2020 条无标签样本（排行榜测试集，标签未公开）。由于无标签样本无法用于评估，本文仅使用前两个文件，并以公开文件的实际内容为准重新构建数据集。

## 3.2 数据质量检查与清洗

在正式实验前，本文对原始数据进行了质量检查，发现三类问题：

1. 训练文件中存在大量重复文本，其中 773 条文本在不同位置被标注为不同标签（标签冲突）；
2. eval_list 中有 1092 条文本同时出现在训练文件中。若直接用 eval_list 作为测试集，模型在测试时会遇到训练中见过的原句，评估结果会因数据泄露而偏高；
3. 上述 1092 条重复文本中，有 228 条在两个文件中的标签不一致，说明部分样本的标注本身存在歧义。

针对这些问题，本文制定了如下清洗规则，并固定随机种子为 42，保证结果可复现：

1. 对文本做 Unicode NFKC 规范化，并去除首尾空白字符；
2. 同一文件内的重复文本，若标签一致则只保留一条，若标签冲突则整组删除；
3. 以 eval_list 作为测试集来源，删除其中与训练文件标签不一致的 228 条样本；
4. 从训练文件中删除所有与测试集相同的文本，彻底消除数据泄露；
5. 对剩余训练数据按类别分层抽样，划出 10% 作为验证集，用于超参数选择和早停。

## 3.5 大语言模型的分类方法

### 3.5.1 提示设计

本文将情感分类表述为对话任务。系统提示为“你是一名金融文本情感分析助手。”，用户提示为：

```
请判断下面这条股民评论的情感倾向，只能回答“消极”“中性”“积极”三者之一，不要输出其他内容。
评论：{评论文本}
```

提示经各模型自带的对话模板渲染后输入模型。对于 Qwen3-8B，本文关闭了其“思考模式”，使模型直接给出答案。少样本设置下，从训练集中每类随机抽取 k 条样本（k = 1 或 3，随机种子 42），以“用户提问—助手回答”的多轮对话形式放在待测评论之前。

### 3.5.2 基于标签词的概率提取

大语言模型通常以自由生成文本的方式作答，这会带来两个问题：一是模型可能输出无法解析的内容；二是只能得到一个离散答案，无法得到各类别的概率，因而无法开展校准和选择性预测分析。为此，本文不让模型自由生成，而是读取模型在答案第一个位置上的输出分布，取出“消极”“中性”“积极”三个标签词首个 token 对应的 logit 值 z₁、z₂、z₃，经 softmax 归一化得到三类概率：

```
P(y = c | x) = exp(z_c) / Σ_j exp(z_j)，  c, j ∈ {消极, 中性, 积极}
```

预测类别取概率最大者，最大概率即作为模型的置信度。实验中确认三个模型的三个标签词首 token 均互不相同，保证了该方法的可行性。

### 3.5.3 LoRA 微调

LoRA（Low-Rank Adaptation）[Hu 等, 2022] 冻结预训练模型的全部原始权重，只在指定的权重矩阵 W 旁并联一个低秩分解 ΔW = BA，其中 B 为 d × r 矩阵，A 为 r × k 矩阵，秩 r 远小于 d 和 k。前向计算变为：

```
h = W x + (α / r) · B A x
```

训练时只更新 A 和 B，可训练参数量从 d × k 降为 r × (d + k)。本文在注意力层的 q、k、v、o 投影和前馈层的 gate、up、down 投影上都加入 LoRA 模块，主实验取 r = 16、α = 32、dropout = 0.05。以 Qwen3-8B 为例，可训练参数为 4365 万，仅占总参数量（82.3 亿）的 0.53%。

训练目标与 3.5.2 节的推理方式保持一致：损失函数为答案位置上正确标签词的交叉熵，等价于只在答案词上计算损失的监督微调。优化器为 AdamW，学习率 1×10⁻⁴，有效批大小 16，训练 2 轮，前 5% 步数线性预热后线性衰减，梯度裁剪阈值 1.0，采用 bf16 混合精度和梯度检查点以节省显存。每轮结束后在验证集上计算 Macro-F1，保留最优一轮的 LoRA 权重用于测试。

为考察量化对效果的影响，本文还实现了 QLoRA [Dettmers 等, 2023]：以 4-bit NF4 格式加载冻结的基础模型权重（采用双重量化），LoRA 模块和计算过程仍使用 bf16 精度。

## 3.6 实验环境与重复设计

全部实验在一台配备 NVIDIA RTX 3090（24 GB 显存）、32 GB 内存的 Windows 计算机上完成，软件环境为 Python 3.11、PyTorch 2.7.1（CUDA 12.8）、transformers、peft 和 bitsandbytes。

为区分模型差异与训练随机性，BERT、RoBERTa 和三个大模型的 LoRA 微调均使用 3 个随机种子（42、43、44）重复训练。零样本推理是确定性的，只运行一次；少样本和消融实验受计算资源限制，只使用种子 42。

## 3.7 评价指标与统计方法

### 3.7.1 分类指标

设类别 c 的精确率为 P_c、召回率为 R_c，则其 F1 值为 F1_c = 2P_cR_c / (P_c + R_c)。宏平均 F1 为三个类别 F1 值的算术平均：

```
Macro-F1 = (F1_消极 + F1_中性 + F1_积极) / 3
```

与准确率相比，Macro-F1 对每个类别同等看待，不会因积极类样本多而掩盖模型在少数类上的不足。

### 3.7.2 显著性检验

**McNemar 检验。** 对同一测试集上的两个模型 A 和 B，记 n₀₁ 为 A 对 B 错的样本数，n₁₀ 为 A 错 B 对的样本数。在“两模型错误率相同”的原假设下，带连续性校正的检验统计量为：

```
χ² = (|n₀₁ − n₁₀| − 1)² / (n₀₁ + n₁₀)
```

它近似服从自由度为 1 的卡方分布；当 n₀₁ + n₁₀ < 25 时改用精确二项检验 [McNemar, 1947]。

**Holm 多重比较校正。** 对 m 个模型两两比较时共进行 m(m−1)/2 次检验，若不校正，犯第一类错误的总概率会随检验次数上升。Holm 方法 [Holm, 1979] 将 p 值从小到大排序为 p₍₁₎ ≤ … ≤ p₍ₖ₎，依次与 α/k、α/(k−1)、…、α 比较，第一次不拒绝即停止。它控制了族错误率，同时比 Bonferroni 校正更有检验功效。

**配对 Bootstrap。** McNemar 检验针对的是准确率，而本文的主要指标是 Macro-F1，后者不是逐样本可加的统计量。为此，本文对测试集做有放回重抽样（B = 2000 次），每次在同一组抽样样本上计算两个模型的 Macro-F1 差值，以差值分布的 2.5% 和 97.5% 分位数构成 95% 置信区间 [Efron 和 Tibshirani, 1993]。若区间不包含 0，则认为两模型在 Macro-F1 上存在显著差异。

**方差分析。** 对使用 3 个随机种子的模型，以各次运行的 Macro-F1 为观测值做单因素方差分析，检验不同模型的平均 Macro-F1 是否相同。先用 Levene 检验判断方差齐性，同时报告不要求方差齐性的 Welch 方差分析作为稳健性检验；若整体显著，再用 Tukey HSD 方法做两两事后比较。

需要指出，上述检验针对的是两种不同来源的不确定性：Bootstrap 和 McNemar 检验反映测试样本抽样带来的误差，即“换一批测试数据，结论是否成立”；方差分析反映训练随机性带来的误差，即“重新训练一次，结论是否成立”。本文同时报告两类检验，以更全面地判断模型差异的可靠性。

### 3.7.3 校准分析

一个校准良好的模型，其置信度应与实际准确率一致，例如在所有置信度约为 0.8 的样本上，准确率也应约为 0.8。本文按置信度将测试样本等宽分为 M = 15 个区间 B₁, …, B_M，期望校准误差（ECE）定义为：

```
ECE = Σ_m (|B_m| / n) · |acc(B_m) − conf(B_m)|
```

其中 acc(B_m) 和 conf(B_m) 分别为区间内样本的准确率和平均置信度 [Guo 等, 2017]。此外报告最大校准误差 MCE（各区间差距的最大值）、Brier 分数（预测概率向量与真实标签独热向量的平方误差）和负对数似然 NLL，并绘制可靠性图。

温度缩放 [Guo 等, 2017] 是一种事后校准方法：将 logit 除以一个标量温度 T 后再做 softmax，T > 1 时概率分布变得更平缓，可以缓解过度自信。T 通过最小化 NLL 估计。由于大模型实验只保存了测试集的预测概率，本文在测试集上采用 5 折交叉拟合：在 4 折上估计 T，应用于剩下的 1 折，保证每个样本的校准概率都来自未见过它的温度估计。

### 3.7.4 选择性预测

在实际应用中，模型可以只对有把握的样本给出判断，对没把握的样本交由人工处理。将测试样本按置信度从高到低排序，只保留前 c 比例的样本作答（c 称为覆盖率），计算这部分样本的错误率（风险），得到风险-覆盖率曲线。曲线下面积 AURC 越小，说明模型的置信度越能区分对错 [Geifman 和 El-Yaniv, 2017]。由于 AURC 也受模型整体错误率影响，本文同时报告 E-AURC，即 AURC 减去在同样错误率下按理想排序可达到的最小 AURC，它只衡量置信度排序的质量。

第一，LoRA 微调后的三个大模型取得了最好的效果，Macro-F1 在 0.798～0.807 之间，准确率在 81.8%～82.6% 之间。其中 Qwen2.5-7B 的平均 Macro-F1 最高（0.807），但三个大模型之间的差距不超过 0.01。

第二，不经微调的大模型表现较差。三个模型零样本的 Macro-F1 只有 0.644～0.666，甚至低于最简单的 TF-IDF + 逻辑回归（0.702）。这与 DISC-FinLLM [Chen 等, 2023] 等研究报告的通用大模型在 FinFE 上准确率约为 60%～69% 的结论一致，说明通用大模型虽然具备一般的语言理解能力，但并不熟悉股民评论的表达习惯和标注标准。

第三，提供示例的作用有限且不稳定。每类给出 3 个示例时，Qwen3-8B 的 Macro-F1 从 0.644 提高到 0.696，Qwen2.5-7B 从 0.666 提高到 0.690，而 GLM-4-9B 反而从 0.661 下降到 0.627。每类只给 1 个示例时，GLM-4-9B 同样下降（0.630），Qwen2.5-7B 基本不变（0.666）。可见少样本提示的效果因模型而异，远不如微调可靠。

第四，所有模型在中性类上的 F1 都明显低于另外两类。即使是表现最好的模型，中性类 F1 也只有 0.707，比积极类低约 17 个百分点。结合 3.3 节的描述性统计，中性评论多为提问或客观陈述，与带有轻微情绪的消极、积极评论边界模糊；数据清洗中发现的 228 条跨文件标签不一致样本也说明，人工标注在这些样本上同样存在分歧。

### 4.2.4 检验结果的综合解读

三类检验对“LoRA 大模型是否优于 RoBERTa”给出了不同强度的证据：方差分析给出显著结论，配对 Bootstrap 给出边缘显著结论，McNemar 检验则不显著。这一差异并不矛盾，而是反映了不同来源的不确定性：大模型每次训练都稳定地比 RoBERTa 高约 2 个百分点，训练随机性带来的波动（标准差 0.002～0.007）远小于这一差距，因此方差分析能够检出；但测试集只有 1713 条，测试样本抽样误差的量级（Macro-F1 的置信区间半宽约 0.02）与这一差距相当，因此从“推广到新数据”的角度看，证据仍然偏弱。

综合来看，本文的结论是：LoRA 微调后的大模型相对 RoBERTa 具有稳定但幅度较小的优势，三个大模型之间没有显著差异。这也提示，只报告单次运行的分数，或只使用一种检验方法，都可能对模型差异得出过于乐观或过于保守的判断。

**训练样本量。** 只用 500 条样本微调，Macro-F1 就从零样本的 0.644 提高到 0.766，接近用全部 8802 条数据训练的 RoBERTa（0.778）。此后继续增加数据，效果提升逐渐放缓：从 500 条增加到 8802 条，数据量增加约 17 倍，Macro-F1 只提高 3.4 个百分点。这说明大模型只需少量标注数据就能适应任务，在标注成本较高的金融场景中有实际意义。

**量化精度。** 4-bit 量化将训练峰值显存从 18.3 GB 降到 11.2 GB，降幅约 39%，而 Macro-F1 没有下降（0.807 对 0.800），代价是训练时间从 38 分钟增加到 44 分钟。这意味着显存 12 GB 的消费级显卡也能完成 8B 规模大模型的微调，进一步降低了大模型在金融文本分析中的应用门槛。

## 4.6 数据泄露对评估结果的影响

为检验 3.2 节数据清洗的必要性，本文模拟了直接使用公开数据的常见做法：不去重、不处理冲突，在原始训练文件（随机划出 10% 作验证集）上训练 TF-IDF + 逻辑回归和 RoBERTa（3 个种子），在原始 eval_list 的全部 2020 条样本上测试。根据测试样本是否在训练文件中出现过，把测试集分为三组：训练中出现过且有相同标签（seen_same，868 条，占 43%）、训练中出现过但标签不同（seen_diff，229 条）、训练中未出现过（unseen，923 条）。结果见表 4-9。需要说明的是，这里按原始文件逐行计数，且未先去除各文件内部的重复与冲突，因此“见过”的样本合计 1097 条、标签不同的 229 条，与 3.2 节在文件内去重后统计的 1092 条和 228 条略有差别，两者口径不同，但结论一致。

> 表 4-9 未清洗数据上训练与测试的结果（Macro-F1，RoBERTa 为 3 个种子均值）

| 测试子集 | 样本数 | TF-IDF+LR 准确率 | TF-IDF+LR Macro-F1 | RoBERTa 准确率 | RoBERTa Macro-F1 |
| --- | --- | --- | --- | --- | --- |
| 全部测试集 | 2020 | 0.770 | 0.755 | 0.788 | 0.773 |
| 见过且标签相同（seen_same） | 868 | 0.968 | 0.967 | 0.926 | 0.923 |
| 见过但标签不同（seen_diff） | 229 | 0.052 | 0.055 | 0.214 | 0.217 |
| 未见过（unseen） | 923 | 0.763 | 0.673 | 0.801 | 0.740 |
| 参照：清洗后测试集 | 1713 | 0.734 | 0.702 | 0.802 | 0.778 |

结果揭示了泄露的三个影响：

第一，模型会“背答案”。对训练中见过的原句，TF-IDF 的准确率高达 96.8%，RoBERTa 为 92.6%，远高于未见过样本上的 76.3% 和 80.1%；而对训练中标签不同的 229 条样本，两个模型的准确率只有 5.2% 和 21.4%，说明它们基本是在复现训练中记住的标签。

第二，泄露使分数偏离模型真实的泛化能力，偏离程度因模型而异。以未见过样本上的 Macro-F1 作为真实泛化能力的估计，TF-IDF 在全部测试集上的分数虚高了 8.1 个百分点（0.755 对 0.673），RoBERTa 虚高了 3.3 个百分点（0.773 对 0.740）。依赖词面匹配的 TF-IDF 更善于记忆原句，受益更多。

第三，泄露会扭曲模型之间的比较。在未清洗的全部测试集上，RoBERTa 只比 TF-IDF 高 1.9 个百分点；但在未见过的样本上，两者差距为 6.7 个百分点，在清洗后的测试集上为 7.7 个百分点。也就是说，泄露把两类模型的真实差距缩小了约三分之二，可能导致研究者低估更强模型的优势。

此外，比较两种训练方式在“未见过”文本上的表现：未清洗数据训练的 RoBERTa 在 923 条未见过样本上的 Macro-F1 为 0.740，清洗后数据训练的 RoBERTa 在其中同时属于清洗后测试集的 845 条样本上为 0.739，两者基本持平（两个子集大部分重合但不完全相同，此比较为近似）。这说明清洗虽然删除了部分训练样本，但没有明显损害模型的泛化能力。

| 估计的单次标注正确率 q | 0.908（95% CI：0.899～0.918） |
| 冲突配对中：消极—中性 / 中性—积极 / 消极—积极 | 475 / 374 / 186 |

同一条文本的两次标注只有 82.9% 是一致的，机会校正后的 κ 为 0.735，按常用标准属于“较高但不完全”的一致性。假设每次标注以概率 q 给出真实标签、否则等可能地给出另外两类之一，则两次标注一致的概率为 p = q² + (1 − q)²/2，解得 q = [1 + √(6p − 2)]/3 ≈ 0.908。这意味着，即使一个模型能完全预测出真实情感，它与数据集标签的一致率也只有约 91%，可以把 91% 看作该数据集上准确率的近似上限。

这一分析有三点启示：

1. 本文最好的模型准确率约为 82%，距离约 91% 的上限仍有约 9 个百分点的空间，模型仍有改进余地；
2. 值得注意的是，LoRA 大模型与数据标签的一致率（约 82%）已与两次人工标注之间的一致率（82.9%）相当，即模型与标注者的一致程度已接近标注者与标注者之间的一致程度；
3. 在全部 1035 个冲突配对中，有 849 个（82%）涉及中性类，这从数据层面解释了 4.1 节中各模型在中性类上表现最差的现象：中性类的边界本身就存在较大的主观分歧。

需要说明的是，被重复标注的文本平均长度（18.5 个字符）略短于全部文本（21.1 个字符），并非完全随机的样本，且上述噪声模型假设各类错误等可能发生，因此 91% 的上限应视为粗略估计。

## 4.8 本章小结

本章从分类效果、统计显著性、校准、选择性预测和数据质量五个方面对实验结果进行了分析，主要结论如下：

1. LoRA 微调是提升大模型效果的关键。三个大模型经 LoRA 微调后，Macro-F1 从零样本的 0.64～0.67 提升到 0.80 左右，而少样本提示的效果有限且不稳定。
2. LoRA 微调后的大模型相对 RoBERTa 具有稳定但幅度较小的优势（约 2 个百分点）。这一优势在多种子方差分析中显著，在配对 Bootstrap 中边缘显著，在 McNemar 检验中不显著；三个大模型之间没有显著差异。
3. 大模型存在过度自信问题，零样本时尤其严重；温度缩放能够有效纠正，使 LoRA 大模型成为校准最好的模型。
4. 在选择性预测中，LoRA 大模型的置信度排序质量最好，只回答最有把握的一半评论时准确率可达 96% 左右。
5. 大模型只需 500 条标注样本即可接近 RoBERTa 用全部数据训练的效果；较小的 LoRA 秩和 4-bit 量化均不会明显降低效果，4-bit 量化可节省约 39% 的显存。
6. 中性类是所有模型的共同难点：重复标注中 82% 的冲突涉及中性类，说明其边界本身存在主观分歧。
7. 数据泄露会让模型“背答案”，使 TF-IDF 的分数虚高 8.1 个百分点，并把 TF-IDF 与 RoBERTa 的真实差距缩小约三分之二；清洗数据没有明显损害模型的泛化能力。
8. 重复标注的一致率仅为 82.9%（κ = 0.735），据此估计该数据集的准确率上限约为 91%；LoRA 大模型与标签的一致率已接近人工标注之间的一致率。
