# 本文的创新点

本文件与当前论文第 1、3、4 章口径一致，用于答辩陈述。贡献在数据质量和评估设计，不在提出新的 LoRA 或保形预测算法。

## 绪论用段落

第一，**识别并处理公开基准数据的重复与冲突，并明确评估曝光口径。** 原始 2020 条评估记录中，有 1097 条规范化文本也出现在原始训练文件中；文件内去重、去冲突后，两文件仍有 1092 个重叠文本，其中 228 个标签不同。本文区分实际训练曝光与验证曝光，在同样的 845 条共同未曝光文本上比较清洗前后的模型结果，并给出可复现的数据处理规则。不同评估子集的分数差只作描述，不解释为纯泄漏因果效应。

第二，**区分两种不确定性来源，并控制多重比较。** 多种子方差分析考察固定数据划分下的训练随机性；McNemar 与配对 Bootstrap 考察给定训练结果下的测试样本抽样误差。本文分别使用 Holm 校正和十对比较的 Bonferroni 区间。LoRA 大模型在所考察的三个种子中均取得更高的 F1 点估计，但种子 42 的大模型对 RoBERTa 的差异，在多重比较调整后未达到显著水平，不能推广为对新数据的稳定优势。

第三，**联合分析概率校准、选择性预测和集合预测。** Qwen3 零样本的平均置信度为 96.4%，实际准确率为 67.1%；LoRA 模型经测试分布内五折温度交叉拟合后，ECE 为 0.013～0.030。在选择性预测中，只处理置信度最高的 50% 样本时准确率约为 96%。标准保形预测整体覆盖率约为 90%，约 77%～78% 的预测集合是单元素，但单元素子集的准确率约为 88.7%～89.3%，不具有自动推出的 90% 条件保证。本文同时披露历史概率存储精度对零样本 NLL 与温度估计的影响。

第四，**描述重复记录中的标签分歧，并限定噪声推算的含义。** 配对标签一致率为 82.9%，基于配对两端汇总边际的机会校正一致性指标 K_pair 为 0.742，82% 的冲突涉及中性类。独立对称噪声模型下可推算 q 约为 0.908，但由于缺少独立复标证据且清洗改变了评估样本，不将其解释为清洗后测试集的准确率上限，也不据此宣称模型接近人工水平。


## 答辩时的注意事项

- 不把不同测试子集的 8.1 个百分点差解释为纯泄漏效应，不把验证集曝光说成训练中“背答案”。
- 显著性必须交代数据划分、训练种子、评价指标和多重比较方法；三次运行的点估计更高不代表对新数据稳定优越。
- 整体集合覆盖率 90% 不等于单元素答案正确率 90%；本实验后者约为 88.7%～89.3%。
- 0.908 仅为独立同质对称噪声假设下的 q 情景推算，不是清洗后测试集上限；重复记录不能自动视为独立人工复标。
- 零样本 NLL 和温度依赖历史概率的存储及截断约定；未重新推理恢复高精度输出前，不宣称该问题已经消除。
