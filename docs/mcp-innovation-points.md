# 本文的创新点

本文档整理论文的创新点，可直接改写进第 1 章绪论的“研究创新”小节，也可用于答辩陈述。所有数据均来自本文实验，见第 3、4 章。

## 绪论用段落

与已有研究相比，本文的创新主要体现在以下四个方面。

第一，发现并修正了公开基准数据的质量问题，并量化了其对评估的影响。本文发现 FinFE 公开评估集中有 1092 条文本（占 54%）原样出现在训练集中，其中 228 条标签不一致。对照实验表明，数据泄露使模型对见过的原句准确率高达 93%～97%，使 TF-IDF 基线的分数虚高 8.1 个百分点，并把 TF-IDF 与 RoBERTa 的真实差距缩小约三分之二。本文给出了可复现的清洗规则和无泄露的数据划分。

第二，从统计学角度区分了两种不确定性来源，对模型差异做出更稳健的判断。已有大模型研究多只报告单次运行的分数。本文对多个模型各进行 3 次独立训练，并同时使用多种子方差分析（反映训练随机性）、配对 Bootstrap 和经 Holm 校正的 McNemar 检验（反映测试样本抽样误差）。结果显示，LoRA 大模型相对 RoBERTa 约 2 个百分点的优势在前者中显著、在后者中仅边缘显著或不显著，从而得出“优势稳定但幅度较小”的审慎结论。

第三，将校准分析与选择性预测引入中文金融情感分类的大模型评估。本文基于标签词 logit 提取三类概率，发现零样本大模型平均置信度为 96.4%，而实际准确率仅为 67.1%；LoRA 微调后仍存在过度自信，温度缩放可将期望校准误差降至 0.013～0.030。在选择性预测中，LoRA 大模型只回答置信度最高的 50% 样本时准确率约为 96%，为人机协作的舆情监测提供了依据。

第四，利用重复标注估计了数据集的标注噪声和准确率上限。同一文本两次标注的一致率仅为 82.9%（κ = 0.735），据此估计准确率上限约为 91%；82% 的标注冲突涉及中性类，从数据层面解释了中性类识别困难的原因，并表明 LoRA 大模型与标签的一致率已接近人工标注之间的一致率。

## 答辩时的注意事项

- LoRA、QLoRA、标签词概率提取等都是已有方法，本文是应用和组合，不要说成“提出”。
- 本文不是“首次”用大模型做金融情感分析，创新在数据质量、评估方法和统计分析。
- 91% 的准确率上限是基于简化噪声模型的粗略估计，被重复标注的文本也不是随机样本。
- 显著性结论要说清楚是针对哪种不确定性：训练随机性下显著，测试抽样误差下边缘显著或不显著。
