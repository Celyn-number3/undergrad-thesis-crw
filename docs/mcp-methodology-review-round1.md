## 1. 必须改：总体覆盖率不等于“唯一答案有 90% 保证”

**位置：** `docs/mcp-thesis-ch3-ch4.md:430–474`，尤其 456、474 行；实现见 `src/analysis/conformal.py:25–42`。

正文前面对“可交换条件下的集合覆盖率”的定义基本正确，但随后写成“约四分之三的评论可以给出有 90% 保证的唯一答案”。这是把总体保证误当成筛选出单元素集合后的条件保证。

按原程序的种子、1000 次划分、标准方法和 90% 目标复算，并补算单元素集合的正确率：

| 模型 | 总体集合覆盖率 | 单元素集合比例 | 单元素集合内准确率 |
| --- | ---: | ---: | ---: |
| Qwen3 LoRA | 90.05% | 77.89% | **89.25%** |
| Qwen2.5 LoRA | 90.08% | 77.09% | **89.31%** |
| GLM LoRA | 90.10% | 77.67% | **88.75%** |

最后一列将各次划分的单元素预测汇总计算，是重复划分描述量；不是将这些重复出现的样本当成独立新样本来构造置信区间。

**影响：** 关于“自动输出唯一类别仍有 90% 保证”的应用结论不成立；原有整体覆盖率结果并未因此失效。文献也明确区分 marginal coverage 与 conditional coverage。[1](https://arxiv.org/html/2107.07511v6)

**最小修改：** 改为“整体预测集合在交换性假设下具有 90% 的边际覆盖保证；本实验约 77%–78% 的预测集合为单元素，其子集准确率另行报告，不具有由此自动推出的 90% 保证”。保留现有表，增加最后一列即可，不需要训练。

## 2. 必须限定：8.1 个百分点不是已识别的纯泄漏效应

**位置：** `docs/mcp-thesis-ch3-ch4.md:381–401`；`src/analysis/leakage.py:44–79`。

有两层问题：

1. **分组定义混用了训练和验证。** 代码把未清洗版 train 与 val 合并后判断“见过”。其中 **108 条原始评估记录只在验证集中出现，不在实际优化训练集出现**。按实际训练集重分，seen_same / seen_diff / unseen 为 **787 / 202 / 1031**，不是正文的 868 / 229 / 923。验证集参与调参也会形成评估信息污染，但不能统称为“训练中见过并背答案”。
2. **“虚高 8.1”比较的是不同样本总体。** 0.7547 − 0.6733 = 0.0814，是同一未清洗模型在全部评估集与 unseen 子集的 Macro-F1 差；不是同一固定测试集上“有泄漏/无泄漏”的受控差。unseen 子集中积极类占 582/923 = **63.1%**，seen_same 中仅 244/868 = **28.1%**，两组构成明显不同。Macro-F1 也不是按子集占比线性加权的指标。

我另外将两种训练方式严格对齐到**同样 845 条、相同标签的共同 unseen 文本**：RoBERTa 三种子平均 F1 为 **0.7309 → 0.7392**；TF-IDF 为 **0.6543 → 0.6583**。这是更可比的清洗策略比较，但仍不是只改变泄漏这一因素的因果实验。

**影响：** “有数据重复和评估污染”的判断有证据；“纯由泄漏造成 8.1 个百分点虚高、真实模型差距缩小三分之二”的定量归因过强。

**最小修改：** 区分训练曝光与验证曝光；将 8.1 写为“全体评估与未曝光子集的观察差值”，删去“真实差距”和纯因果措辞；以共同 845 条结果替代 923 对 845 条的近似比较。若坚持估计纯泄漏效应，需另做固定测试集、控制其他因素的实验，当前不执行。

## 3. 必须改：91% 是假设下的模型推算，不是已测得的性能上限

**位置：** `docs/mcp-thesis-ch3-ch4.md:405–426`、`docs/mcp-thesis-ch5.md:17`；`src/analysis/label_noise.py:47–82`。

**核实结果：** 5575 个重复文本、6048 个配对、一致率 0.828869，以及公式算出的 q = 0.908100 均可复算，算术没有错。

**问题：** 公式还需要“给定真实类别，两次标注独立、正确率相同、错误对另两类均匀分配”等假设。原始记录只有文本和类别，没有标注者 ID、独立复标过程或金标准；重复记录不自动等于两位独立标注者的判断。此外，估计来自原始重复文本，主测试集却已经删除部分标签冲突样本，不能直接把 q 当成清洗后测试集的上限。

正文虽已说明“非随机样本、粗略估计”，但尚未解决独立复标来源和外推对象的问题。因此“模型约 82%，已接近人工间一致程度”的比较也应降级为数值描述，而非接近人工水平的证据。

**最小修改：** 将“准确率上限”改为“独立对称噪声假设下的标注正确率情景估计”；保留重复记录的一致性分析，撤回可直接套用于清洗后测试集的上限结论。要把它提升为实证结论，需要独立复标材料，不必为改文字重训模型。

## 4. 需补数值处理：概率四舍五入后再取对数，影响零样本 NLL 与温度

**位置：** `src/utils/metrics.py:33–40` 将概率 `.round(6)` 后存盘；`src/analysis/stats.py:230–260` 将零概率截到 1e-12 后取 log；正文 `docs/mcp-thesis-ch3-ch4.md:314–327,460`。

Qwen3 零样本保存的概率中，有 **91 条样本的真实类别概率为 0**。在同一份 CSV 上，仅改变无法还原的零值所采用的截断下限，就得到：

| 截断下限 | 原始 NLL | 五折平均温度 T |
| --- | ---: | ---: |
| 1e-6 | 2.5962 | 6.5507 |
| 1e-8 | 2.8408 | 7.5518 |
| 1e-12（原实现） | 3.3301 | 9.8543 |

**影响：** 3.33 和 9.85 不是仅由保留的模型信息唯一确定的数值；概率尾部精度已经丢失。“零样本模型过度自信”的方向仍有平均置信度/准确率等证据支持，但不能忽略存储精度来解释 NLL、最优温度及极端概率并列现象。Qwen3 LoRA 本次检查未出现零概率，不能把上述影响泛化到全部模型。

**最小修改：** 不要靠把下限从 1e-12 换成 1e-6 就宣布修复。应优先保存未舍入概率或三类 logits/log-probabilities，再计算校准指标；如果原始高精度输出未保留，针对受影响的零样本模型重跑推理即可，不需要训练。改写前保留当前数值，明确标记精度限制；本轮未执行推理。

## 5. 需降级：Bootstrap 的“边缘显著”较脆弱

**位置：** `docs/mcp-thesis-ch3-ch4.md:262–302`；`src/analysis/stats.py:147–161`。

原表的 2000 次 Bootstrap 区间是未做多重比较控制的单次运行区间；McNemar 用了 Holm，并不代表 Bootstrap 也已校正。

在同样种子 42 的预测上，用固定审查 RNG=20261012、10000 次配对重抽样，按“LoRA − RoBERTa”方向：

| 模型 | 点估计差 | 普通 95% 区间 | 针对三个 LoRA-vs-RoBERTa 比较的 Bonferroni 名义同时区间 |
| --- | ---: | --- | --- |
| Qwen3 | 0.01929 | [−0.000031, 0.03918] | [−0.00403, 0.04356] |
| Qwen2.5 | 0.01829 | [0.000776, 0.03631] | [−0.00290, 0.04051] |
| GLM | 0.01816 | [−0.001508, 0.03833] | [−0.00661, 0.04294] |

这些是敏感性复核，不是宣称另一组抽样随机数才是“正确结果”；百分位 Bootstrap 区间及其多重调整仍为近似。Qwen3 的边界可随重抽样落到 0 的另一侧，说明不宜把过/不过 0.05 当成稳定结论。种子 43、44 的逐次检查也显示证据强度会变，详见计算记录。

**最小修改：** 标明单次运行、未校正和探索性；预先说明比较家族，增加重抽样次数并报告调整后的结果。将“优势稳定”限定为“本数据划分和所考察的三个训练种子中，点估计一致更高”。这不否定约 0.80 对 0.778 的观察结果。

## 次要修正与不应误判的事项

- `docs/mcp-thesis-ch3-ch4.md:284`：“Levene 表明方差齐性成立”应为“未检出方差差异”；每组仅 3 次，检验功效有限。
- `src/analysis/stats.py:295–302`：图 4-1 的柱高是三种子均值，误差线却来自种子 42。表注已解释，但图形仍容易误读；建议用均值 ± SD，或让柱高也对应种子 42。
- `src/analysis/label_noise.py:64–66`：κ 的随机一致率使用全部记录类别比例，而非配对样本的边际比例。当前 0.7348 是特定自定义口径；用配对两端汇总边际作敏感性计算为 0.7417，但后者也不能未经说明称为“修正后的标准 Cohen κ”。应定义系数及抽样单位。
- 第 3.7.3 节明确披露了测试集五折交叉拟合，每条记录自身标签没有用于拟合它对应的温度；**不能直接判成同一条样本上的拟合—评估泄漏**。但它是该测试分布内的交叉拟合结果，不是独立外部测试，也没有得到一个已独立验证的部署温度。
- 保形预测将原测试集再分为校准/评估，当前代码没有把同一次划分的评估标签用于求阈值。1000 次重复仍是同一批数据的重用，不能说等于 1000 个独立外部验证集。

## 建议处理顺序

1. **不新增训练即可完成：** 修正第 1、2、3 项的结论边界，补共同样本比较和单元素准确率，收紧第 5 项措辞。

3. **单独确认后再做：** 查找高精度零样本输出；若没有，仅重新推理并补存 logits。当前不要启动全面重训。
