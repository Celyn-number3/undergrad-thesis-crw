# 实验设计与数据说明

本文档记录论文《基于LoRA微调的大语言模型中文金融情感分类研究》的实验环境、数据处理和整体实验方案。

## 1. 实验环境

| 项目 | 配置 |
| --- | --- |
| GPU | NVIDIA RTX 3090（24 GB 显存） |
| 内存 | 32 GB |
| 系统 | Windows，Anaconda 环境 `thesis` |
| Python | 3.11 |
| 深度学习框架 | PyTorch（CUDA 12.8）、transformers、peft、bitsandbytes |
| 统计分析 | scikit-learn、statsmodels、scipy |

一键安装：`bash scripts/setup_env.sh`；检查环境：`python src/utils/check_env.py`。

## 2. 数据集：FinFE

FinFE 来自 BBT-CFLEB 中文金融评测基准，内容是股民在金融社交媒体上的短评，分三类情感：0 = 消极，1 = 中性，2 = 积极。

### 2.1 公开数据与论文描述不一致

原论文写的是 8000/1000/1000 的划分，而 GitHub 上公开的文件实际是：

| 文件 | 条数 | 是否有标签 |
| --- | --- | --- |
| train_list.json | 16157 | 有 |
| eval_list.json | 2020 | 有 |
| problem_list.json | 2020 | 无（排行榜测试集，本研究不使用） |

原始数据描述与本文实际使用的数据划分区分记录，当前正文以清洗后的实际样本数为准。

### 2.2 发现的数据质量问题

1. 训练文件中有大量重复文本，其中 773 条文本在不同位置被标成了不同标签（标签冲突）；
2. 原始 2020 条评估记录中有 1097 条规范化文本也在原始训练文件中出现；该文件之后还划出验证集，实际训练曝光与验证曝光需分别统计；
3. 各文件内部去重、去冲突后，跨文件仍有 1092 个重叠文本，其中 228 个标签不同。

### 2.3 清洗与划分规则

由 `src/data/prepare_finfe.py` 实现，随机种子固定为 42：

1. 文本做 Unicode NFKC 规范化并去掉首尾空白；
2. 同一文件内重复的文本：标签一致只保留一条，标签冲突则整组删除；
3. 测试集取 eval_list，并删除与训练文件标签不一致的 228 条；
4. 训练池中删除所有与文件内清洗后评估集合重叠的文本（含随后从测试集删除的 228 个跨文件冲突文本），排除完全重复的跨集合重叠；
5. 剩余训练数据按类别分层抽取 10% 作为验证集。

### 2.4 最终数据规模

| 数据集 | 消极 | 中性 | 积极 | 合计 |
| --- | --- | --- | --- | --- |
| 训练集 | 2044（23.2%） | 1845（21.0%） | 4913（55.8%） | 8802 |
| 验证集 | 227（23.2%） | 205（20.9%） | 547（55.9%） | 979 |
| 测试集 | 461（26.9%） | 438（25.6%） | 814（47.5%） | 1713 |

清洗涉及按标签冲突删除评估记录，改变了样本构成；不据此声称原始总体无偏，也未排除全部近重复。测试集的类别比例与训练集有显著差异（卡方检验 p < 0.001），而且类别本身不均衡，所以主要评价指标采用宏平均 F1（Macro-F1），准确率作为辅助指标。

## 3. 描述性统计的主要发现

详细表格见 `outputs/eda/summary.md`，图片见 `outputs/eda/*.png`。

- 文本很短，平均约 21 个字符，最长不到 70 个字符；
- 积极类文本明显更长（Kruskal-Wallis 检验 p < 0.001）；
- 消极类文本更常出现否定词，中性类更常出现问号（多为提问），积极类更常出现感叹号；
- 高频词符合直觉：消极类有“垃圾、跌停、大跌”，积极类有“涨停、加油、加仓”。

## 4. 实验方案

| 编号 | 实验 | 目的 |
| --- | --- | --- |
| E1 | 传统基线：TF-IDF + 逻辑回归 / SVM | 提供非深度学习参照 |
| E2 | 预训练小模型微调：中文 BERT / RoBERTa | 提供常规深度学习参照 |
| E3 | 大模型零样本与少样本提示 | 衡量不微调时的能力 |
| E4 | 大模型 LoRA 微调（主实验） | 比较不同大模型的效果 |
| E5 | 消融：LoRA 秩、训练样本量、4-bit 量化 | 分析关键因素的影响 |
| E6 | 统计检验：McNemar + Holm 校正、50000 次配对 Bootstrap + 十对比较 Bonferroni 区间、多随机种子方差分析 | 判断差异是否显著 |
| E7 | 校准与选择性预测：ECE、可靠性图、温度缩放、AURC | 判断模型的“自信”是否可信 |

大模型输出的类别概率取自三个标签词在下一个词位置上的 logits 经 softmax 得到，这样 E7 才能计算校准指标。

## 6. 本轮方法修订口径

- 区分优化训练曝光与验证曝光；清洗策略在相同的 845 条共同未曝光文本上比较，不把不同子集分数差当成纯泄漏效应。
- 重复记录只有文本和标签，无独立复标凭证；使用配对边际定义 K_pair，q 仅作独立对称噪声假设下的情景推算。
- 保形预测的整体覆盖保证不适用于自动筛选出的单元素子集，后者准确率单独报告。
- 历史概率只存六位小数，NLL 及温度截断敏感性见 `outputs/analysis/probability_precision.csv`。后续保存已取消预先舍入；本轮没有重跑推理，历史精度丢失仍待处理。
